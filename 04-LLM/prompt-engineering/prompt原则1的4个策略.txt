Prompt工程原则1：编写清晰、具体的指令（Write clear and specific instructions）

一个好的Prompt首先需要保证指令清晰明确，让AI准确理解任务目标、输入内容和输出要求。

1. 使用分隔符（Delimiters）

在Prompt中使用特殊符号区分不同的信息区域，可以帮助AI明确哪些是背景信息、任务要求以及需要处理的内容，减少理解错误。

常见分隔符包括：

三引号：
"""内容"""

三反引号：
```内容```

三横线：
---内容---

尖括号：
<内容>

XML标签：
<tag>内容</tag>

例如：
请分析下面的文章：
"""
这里放需要分析的文章内容
"""

通过分隔符，AI可以清楚识别用户提供的数据和具体任务。


2. 要求结构化输出（Ask for structured output）

在使用AI时，不仅要告诉它做什么，还可以规定输出格式，让结果更加稳定、方便使用。

常见结构化输出格式：

JSON：
{
 "任务": "内容"
}

HTML

Markdown表格

例如：
不要只说：
“帮我分析这份数据”

可以要求：
“请使用JSON格式输出结果，包括问题、原因和解决方案三个字段。”

结构化输出特别适合AI Agent开发，因为Agent需要读取模型返回的数据，并根据结果执行下一步操作。


3. 检查任务条件是否满足（Check whether conditions are satisfied）

在让AI执行任务之前，需要确认完成任务所需的信息是否完整。

需要检查：

- 是否拥有完成任务所需的信息；
- 是否存在未知条件；
- 是否需要额外假设；
- 用户目标是否明确。

例如：
“请先检查我的需求是否完整，如果缺少必要信息，请先向我提问，再开始执行任务。”

这样可以减少AI在信息不足时直接生成错误答案。


4. Few-shot Prompting（少样本提示）

Few-shot Prompting指的是通过提供几个正确示例，让AI学习任务规律，然后完成新的任务。

使用步骤：

第一步：提供几个成功案例；
第二步：展示输入和输出关系；
第三步：要求AI按照相同规律完成新的任务。

例如：

示例：
输入：苹果
输出：水果

示例：
输入：香蕉
输出：水果

任务：
输入：西红柿
请按照示例判断类别。

通过少量示例，可以提高AI对复杂任务的理解能力，使输出更加符合预期。


总结：

高质量Prompt的核心：

明确目标 + 清晰结构 + 输出格式要求 + 条件检查 + 示例引导

在AI Agent开发中，Prompt不仅用于让AI回答问题，更用于控制Agent理解任务、规划步骤、调用工具和执行行动。

好的Prompt = 清晰指令 + 结构化输出 + 条件验证 + Few-shot示例
