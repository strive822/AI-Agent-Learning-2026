# 01-Python-Engineering

本目录用于学习 Python 基础、Python 工程能力和小型脚本项目开发。

## 学习目标

- 从语法学习过渡到函数、模块、文件、异常、测试和项目结构。
- 能独立写出可运行、可维护的小型 Python 程序。
- 为后续 LLM API、RAG 和 Agent 开发打好工程基础。

## 目录用途

- `notes/`：Python 学习笔记。
- `practice/`：语法练习、函数练习和小型实验代码。

## 当前重点

优先补齐：

- 函数设计
- 列表和字典
- 文件读写
- 异常处理
- 模块化
- pytest 基础
