# AI-Agent-Learning-2026

这是一个面向未来六个月的 AI Agent 学习和求职作品集仓库。

仓库目标不是简单保存练习代码，而是持续沉淀：

- Python 工程能力
- 计算机基础
- 后端开发能力
- LLM 应用开发能力
- AI Agent 工作流能力
- 可展示项目
- 深圳 AI Agent / AI 应用开发实习准备材料

## 当前定位

当前阶段：Python 基础到 Python 工程化过渡。

当前重点：

- 函数、数据结构、文件、异常和测试
- Git 记录和学习复盘
- Prompt Engineering 基础资料整理
- 为后续 LLM、RAG 和 Agent 项目打基础

## 六个月主线

```text
Python 工程能力
-> 计算机基础
-> 后端开发
-> LLM 应用开发
-> RAG 与知识库应用
-> Agent Workflow
-> 求职作品集与面试准备
```

## 使用规则

每次学习或开发后，至少沉淀一种内容：

- 学习笔记
- 可运行代码
- 错误记录
- 技术决策
- 周复盘
- 项目说明

练习代码优先放在对应学习模块中，只有具备展示价值的项目才进入 `06-Projects/`。
