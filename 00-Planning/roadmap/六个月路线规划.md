# 六个月路线规划

## 1. 总目标

用 6 个月从 Python 基础阶段进入 AI Agent / AI 应用开发入门到项目实战阶段，并形成能够支持深圳相关实习申请的作品集。

最终交付物不只是“学过”，而是：

- 一个结构清晰的长期学习仓库
- 多个小型 Python 工具项目
- 至少 1 个 LLM 应用项目
- 至少 1 个 RAG 项目
- 至少 1 个 Agent Workflow 项目
- 可写进简历的项目说明
- 面试中能讲清楚的技术决策和踩坑记录

## 2. 阶段路线

### 第 1 月：Python 基础与工程习惯

目标：

- 补齐 Python 函数、列表、字典、文件、异常、模块基础
- 建立命令行运行、Git 记录、学习日志习惯
- 从零散脚本过渡到小型可维护程序

重点内容：

- 函数设计
- 数据结构
- 文件读写
- 异常处理
- 模块与包
- 基础测试

阶段项目：

- Python 学习记录工具
- 简单命令行 Todo
- 文本统计工具

验收标准：

- 能独立写出带函数拆分的小程序
- 能解释每个函数的输入、输出和职责
- 能用 Git 记录一次完整开发过程

### 第 2 月：Python 项目化与 API 基础

目标：

- 具备小型 Python 项目开发能力
- 学会调用 HTTP API
- 理解 JSON、配置文件、环境变量

重点内容：

- requests / httpx
- JSON 数据处理
- `.env` 环境变量
- 项目目录结构
- 日志和错误处理
- pytest 基础

阶段项目：

- 天气查询 CLI
- GitHub 仓库信息查询工具
- API 数据整理小工具

验收标准：

- 能完成一个结构化 Python CLI 项目
- 能安全管理 API Key
- 能写基础测试验证核心逻辑

### 第 3 月：LLM 应用开发基础

目标：

- 理解 LLM API 调用方式
- 掌握 Prompt Engineering 的工程化用法
- 做出第一个可用的 AI 应用

重点内容：

- OpenAI API 基础
- prompt 输入输出结构
- system / user / assistant 消息设计
- 结构化输出
- 简单工具调用思想
- 成本和错误处理

阶段项目：

- AI 学习助手 CLI
- Markdown 笔记总结器
- 简历项目描述生成器

验收标准：

- 能独立调用 LLM API 完成一个真实任务
- 能解释 prompt 为什么这样设计
- 能处理 API 错误、空输出和格式不稳定问题

### 第 4 月：RAG 与知识库应用

目标：

- 理解 RAG 的基本架构
- 能把本地文档接入 AI 问答
- 做出个人学习知识库原型

重点内容：

- 文档加载
- 文本切分
- embedding
- 向量检索
- 检索增强生成
- 引用来源与回答可信度

阶段项目：

- 个人学习笔记问答系统
- 本仓库知识库问答助手

验收标准：

- 能画出 RAG 流程图并解释每一步
- 能说明 RAG 和普通聊天机器人的区别
- 能处理“找不到答案”的情况

### 第 5 月：Agent Workflow 与工具调用

目标：

- 理解 Agent 不是“更聪明的聊天”，而是“带状态、工具和流程的执行系统”
- 学会设计简单工作流型 Agent
- 初步接触 LangGraph 或等价工作流框架

重点内容：

- Agent 状态
- 工具调用
- 任务拆解
- 执行循环
- 中间结果验证
- 简单工作流编排

阶段项目：

- 学习计划 Agent
- GitHub Issue 辅助分析 Agent
- 文档整理 Agent

验收标准：

- 能解释 Agent、Workflow、普通 LLM App 的区别
- 能设计一个带工具调用的小型 Agent
- 能识别失控循环、幻觉和工具错误风险

### 第 6 月：作品集与实习准备

目标：

- 整理项目为可展示作品集
- 准备深圳 AI Agent / AI 应用开发实习
- 建立面试表达能力

重点内容：

- 项目 README
- 项目部署或演示
- 简历项目描述
- 技术亮点提炼
- 面试问答准备
- GitHub 主页整理

阶段项目：

- 选 1 到 2 个项目重点打磨
- 准备作品集说明文档
- 准备实习投递材料

验收标准：

- 至少一个项目能让面试官运行或看懂
- 能讲清楚项目背景、架构、难点、解决方案和改进方向
- 简历中有 AI 应用相关项目经历

## 3. 每周节奏

建议每周保持固定节奏：

- 3 次学习：概念、语法、框架知识
- 2 次编码：小练习或项目功能
- 1 次复盘：整理 DEVLOG、GOTCHAS、DECISIONS
- 1 次输出：README、博客草稿、项目说明或面试表达

## 4. 学习优先级

优先级从高到低：

1. 能独立写代码
2. 能解释代码
3. 能调试错误
4. 能组织项目
5. 能调用 AI API
6. 能做出可展示项目
7. 能讲给面试官听

## 5. 不建议现在做的事

- 不建议立刻深入复杂 Agent 框架
- 不建议一开始就追求大而全项目
- 不建议大量复制 AI 生成代码但不理解
- 不建议把时间耗在频繁换工具上
- 不建议为了“看起来高级”忽视 Python 基础

## 6. 当前下一步

初始化完成后，第一阶段应从 Python 函数开始。

推荐第一批任务：

1. 重构已有 Python 基础脚本为函数版本
2. 增加输入校验和返回值
3. 为核心函数补充简单测试
4. 记录第一篇 DEVLOG 和 GOTCHAS
