# 00-Planning

本目录用于管理未来六个月 AI Agent 学习和求职准备的总体规划。

## 目录用途

- `我的学习档案.md`：记录当前基础、目标、约束和长期方向。
- `roadmap/`：保存六个月路线、阶段目标和里程碑。
- `weekly-progress/`：保存每周进度、复盘和下周计划。
- `learning-log/`：保存学习规则、学习日志和长期方法论。

## 使用规则

- 每周至少更新一次 `weekly-progress/`。
- 每次路线发生明显调整时，同步更新 `roadmap/`。
- 学习方法、复盘规则和协作规则统一沉淀到 `learning-log/`。
